Physical raised keycap (mono label) shown beside actions; KbdHints lays out a key+label row.
```jsx
<KbdHints hints={[{key:'Enter',label:'Correct'},{key:'E',label:'Edit'},{key:'S',label:'Skip'}]}/>
<Kbd down>E</Kbd>
```
Rest = raised (bottom edge shadow); down = pressed flat. "?" conventionally opens the shortcut overlay.
