Standard button for all actions; seal red means action, error red means failure — pick variant accordingly.
```jsx
<Button>Confirm</Button>
<Button variant="secondary">Skip</Button>
<Button variant="destructive" size="sm">Delete document</Button>
```
Sizes: sm 28px, md 32px, lg 36px (work screens), landing 44px (marketing only). Hover deepens fill, active presses in 1px, disabled desaturates toward paper. No transitions.
