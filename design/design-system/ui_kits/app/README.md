# Transcripta app UI kit
Interactive click-through of the product's four surfaces, composed from the design-system components (`window.TranscriptaDesignSystem_fa1864`):
- **Documents** (app shell): status table — processing / done / budget_stop rows; click "Parish register, 1887" to verify, "Upload a PDF" for upload.
- **Upload**: dropzone → selected → determinate progress with mono captions.
- **Verification** (focus shell): split pane (draggable, remembered), context-word marks, kbd hints, page strip, Enter/E/S/? keyboard flow, night-mode toggle.
- **Auth** (centered card): reach via "Sign out".
The scan pane is a labelled placeholder — no real page scans were provided.
